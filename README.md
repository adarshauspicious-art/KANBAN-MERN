# MERN Kanban Board

## Setup

### Backend
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

Backend: http://localhost:5000  
Frontend: http://localhost:5173

for the MongoDB create a something like this :  MONGO_URI=mongodb://127.0.0.1:27017/kanban
